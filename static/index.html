Extractive document summarization · Information Retrieval

Keywords

Sentence relevance

How it works

1 Preprocess: sentence segmentation, tokenization, stopword removal, suffix stemming. 2 Index: each sentence is a document in a TF-IDF vector space. 3 Score: TextRank runs PageRank (d=0.85) on the cosine-similarity graph; TF-IDF sums term weights with position bias; LSA applies SVD via power iteration with deflation (Steinberger–Jezek). 4 Query mode adds Okapi BM25 (k1=1.5, b=0.75). 5 Select: Maximal Marginal Relevance (λ=0.7) removes redundancy. 6 Output in original order. Computation runs on your local Flask + NumPy server (SVD via numpy.linalg).
